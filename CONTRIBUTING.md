# Contributing

Thank you for considering a contribution.

## Development

1. Fork the repository and create a focused branch.
2. Install with `python -m pip install -e .`.
3. Run `python -m unittest discover -s tests -v`.
4. Add tests for behavior changes.
5. Open a pull request with a clear problem statement and validation notes.

Please keep changes small enough to review and avoid adding dependencies unless they provide a clear project-level benefit.
