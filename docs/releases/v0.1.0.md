# Open Data Quality v0.1.0

## Overview

Open Data Quality v0.1.0 is the first public release of a lightweight, configuration-driven data quality toolkit for CSV validation, reporting, and data governance demonstrations.

The project focuses on transparent and repeatable quality checks that can be integrated into data delivery, ETL validation, and governance workflows.

## Highlights

### Data Quality Engine

- Required column completeness checks
- Uniqueness validation
- Regular expression validation
- Numeric range validation
- JSON-based rule configuration

### Reporting

- Machine-readable JSON quality reports
- Self-contained HTML quality reports
- Failed row samples and validation summaries

### Data Governance Demo

Included an environmental monitoring example demonstrating:

- Monitoring station identifier validation
- Duplicate record detection
- PM2.5 value range checks
- Temperature range validation

## Quick Start

```bash
python -m open_data_quality.cli examples/sample.csv --rules examples/rules.json
```

Generate an HTML report:

```bash
python -m open_data_quality.cli examples/sample.csv --rules examples/rules.json --html-report report.html
```

## Project Status

This release provides the foundation for future extensions including database adapters, enterprise data source integration, and AI-assisted rule recommendation.
