# Security Policy

Open Data Quality processes local CSV files and JSON rule files. It does not make network requests during quality checks or send input data to an external service. Do not commit real personal, confidential, or production data to this repository.

Please avoid filing public issues for vulnerabilities that could put users at risk. Use GitHub's private vulnerability reporting feature when available and include the affected version, impact, reproduction details, and suggested mitigation. If private reporting is unavailable, contact the maintainer through the GitHub repository before publishing details.

Security fixes target the latest released minor version. The project does not currently promise security support for unreleased roadmap features or downstream integrations.
